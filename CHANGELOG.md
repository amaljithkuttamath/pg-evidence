# Changelog

## 0.1.0 development preview

- Implement the nine-function PostgreSQL API in Rust with pgrx.
- Retain versioned text and exact citation spans with digest verification, retries,
  revision checks, publication, retirement and logical purge.
- Compose bounded literal, regex, full-text and pgvector search with asset tags
  and one-hop evidence relationships.
- Provide explicit role grants, a text importer, agent-tool examples, independent
  SQL comparisons and a build that exports installable artifacts and evidence.
- Verify the current suite on ARM Linux, including concurrent operations,
  dump/restore and a fresh Docker runtime.

Native x86-64, large-scale performance/recall/memory and live-agent token benefits
remain unverified. TurboQuant is not enabled. License selection and a public
binary/container release remain pending.
